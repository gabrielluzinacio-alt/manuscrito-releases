# Manuscrito Suite — Distribuições oficiais

**Escreva. Organize. Desenvolva. Publique.**

Repositório público dedicado aos instaladores, notas de versão e relatos de problemas dos aplicativos da família **Manuscrito Suite**.

## Aplicativos

- **Manuscrito Literário** — escrita e organização de projetos literários; versão 1.1 beta em distribuição inicial para Windows x64.
- **Manuscrito Acadêmico** — planejado.
- **Manuscrito Digital** — planejado.
- **Manuscrito Estúdio** — planejado.
- **Manuscrito Diagrama** — planejado.

Os produtos planejados ainda não estão disponíveis para download.

## Downloads

Consulte a página de [Releases](../../releases) para obter os instaladores disponibilizados oficialmente.

**Manuscrito Literário 1.1 Beta:** o primeiro pacote previsto é para **Windows x64**. Os instaladores Linux (.deb e .AppImage) e macOS (.dmg Intel e Apple Silicon) ainda dependem de compilação e validação. A disponibilidade efetiva deve ser conferida na lista de Releases.

## Como relatar um problema

Abra uma [Issue](../../issues/new/choose) e utilize o formulário de erro. Informe a versão do aplicativo e do sistema operacional, as etapas para reproduzir o problema, o comportamento esperado e o observado.

**Privacidade:** não anexe manuscritos pessoais, projetos reais, dados sensíveis ou logs sem revisão. Prefira projetos fictícios e arquivos de teste.

## Avisos sobre versões beta

Versões beta são experimentais e podem apresentar defeitos ou incompatibilidades. Faça backup dos seus arquivos antes de instalar ou atualizar. Instaladores ainda não assinados digitalmente podem gerar avisos de segurança; não desative as proteções do sistema para prosseguir.

## Código-fonte e propriedade intelectual

Este repositório concentra **distribuições e documentação pública**, não o código-fonte completo. A disponibilização de instaladores não constitui autorização para reprodução, modificação ou redistribuição fora dos termos aplicáveis. Componentes de terceiros estão sujeitos às respectivas licenças.

## Publicação

As versões são publicadas **manualmente**. Os pacotes disponibilizados nas Releases devem incluir instruções e checksums SHA-256 quando aplicável.
